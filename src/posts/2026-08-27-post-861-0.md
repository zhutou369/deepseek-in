#### 第三步：實施！讓重定向同 404 頁面變有效

DeepSeek 咁多精明建議，最後當然係要將佢哋變成現實啦！不過呢步都講明，你要對網站後台有番咁上下認識先得㗎。

1.  **實施 301 重定向**：
    *   **WordPress 用戶**：可以安裝「Rank Math SEO」、「Yoast SEO」或「Redirection」呢類外掛（Plugin）。喺外掛設定頁面，你可以逐一或者批量輸入舊網址同 DeepSeek 建議嘅新網址，選擇 301 永久重定向。操作簡單，適合非技術背景嘅站長。
    *   **Apache 伺服器 (.htaccess)**：如果你網站係行 Apache 伺服器，你可以編輯網站根目錄下嘅 `.htaccess` 檔案。加入類似以下嘅重定向規則：
        ```apache
        Redirect 301 /舊網址 /新網址
        # 或者使用 RewriteRule 處理更複雜嘅情況
        RewriteEngine On
        RewriteRule ^舊路徑$ /新路徑 [R=301,L]
        ```
        **請注意**：修改 `.htaccess` 檔案有機會導致網站錯誤，務必喺修改前備份！
    *   **Nginx 伺服器**：編輯你網站嘅 Nginx 配置檔。例如：
        ```nginx
        server {
            # ... 其他配置
            rewrite ^/舊路徑$ /新路徑 permanent;
            # 或者
            location = /舊網址 {
                return 301 /新網址;
            }
        }
        ```
        同樣，修改配置檔前記得備份，並喺重啟 Nginx 服務前測試配置語法。
2.  **更新 404 錯誤頁面**：
    *   **WordPress 用戶**：好多主題都會有自訂 404 頁面嘅功能。你亦可以安裝「Custom 404 Pro」呢類外掛，直接將 DeepSeek 生成嘅內容貼入去。如果你熟悉 HTML/CSS，可以直接修改主題文件 `404.php`。
    *   **其他網站**：通常你需要編輯你網站伺服器嘅錯誤頁面配置（例如 Apache 嘅 `ErrorDocument 404 /404.html`）或者直接修改你網站嘅 404 頁面檔案（通常係 `404.html` 或 `404.php`），將 DeepSeek 提供嘅內容整合入去。
3.  **重新提交網站地圖（Sitemap）**：做完大量重定向後，記得喺 Google Search Console 重新提交你網站嘅 XML Sitemap，通知搜尋引擎機械人重新爬取你嘅網站，更快地發現呢啲更新。
4.  **定期監測**：重定向並非一勞永逸。定期用第一步講到嘅工具再次掃描網站，確保冇新嘅死鏈出現，並監測重定向是否生效。

### 常見問題

**Q1：DeepSeek 點幫我搵死鏈？**

A1：DeepSeek 自己唔會直接幫你掃網站搵死鏈㗎。佢做嘅係食咗你俾嘅死鏈清單，再根據你網站嘅主題同內容，幫你諗出每個死鏈最啱 redirect 去邊個新網址（301 重定向），又或者教你點樣將 404 頁面搞靚啲，吸引返啲訪客留低。所以話，第一步用工具掃描真係好關鍵！

**Q2：404 頁面可以放啲咩內容？**

A2：除咗 DeepSeek 建議嘅友善訊息、解釋同引導，你可以考慮加入：熱門文章/產品推薦、搜尋框、最新活動資訊、你網站嘅聯絡方式，甚至係一個訂閱電子報嘅表格。目標係將一個潛在嘅負面體驗轉化為一個再次互動嘅機會。

**Q3：301 重定向同 302 有咩分別？我應該用邊種？**

A3：301 係「永久重定向」，表示頁面已經永久移動到新網址，並會將舊網址嘅大部分 SEO 權重傳遞到新網址。302 係「臨時重定向」，表示頁面暫時移動。如果你係想修復死鏈或者頁面永久搬家，**絕大部分情況下都應該用 301 重定向**，以保留 SEO 價值。DeepSeek 亦會優先建議 301。
