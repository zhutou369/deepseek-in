## 第三步：前後端數據對接與測算邏輯

搞掂咗前後端，呢步就係將用戶打嘅字傳畀 DeepSeek，再將 AI 嘅結果彈返出嚟。

1.  **小程序嗰邊 (JavaScript)**：喺 `pages/index/index.js` 度寫番啲邏輯：
    *   **點樣收用戶輸入**：`onKeywordsInput` 事件會幫你將用戶輸入嘅關鍵詞記低到 `data` 變數度。
    *   **發送 API 請求**：當用戶撳掣 (`startCalculation` 函數) 嗰陣，用 `wx.request` 發個請求去你嘅後端服務。**超重要提示：為咗安全起見，千祈唔好直接喺小程序前端叫 DeepSeek API！一定要經自己個後端服務轉個手。** 咁做可以收埋你條 API Key，順便仲可以加啲其他處理，好似限住請求次數咁。
    *   **顯示載入中**：發咗請求之後，最好顯示個 `loading` 狀態，等用戶知你做緊嘢，體驗會好啲。
    *   **處理 AI 回應**：後端傳返 DeepSeek 測算結果過嚟之後，更新 `data` 入面嘅 `result` 變數，介面就會自動顯示出嚟。

2.  **後端服務 (例如用 Node.js 配 Express 或者 Python 配 Flask 都得)**：
    *   起個簡單嘅 API 接口，收晒小程序傳過嚟嘅用戶關鍵詞。
    *   喺後端，可以用 DeepSeek 嘅 SDK 或者直接發 HTTP 請求到 DeepSeek API 接口 (好似 `https://api.deepseek.com/chat/completions`)。
    *   將之前設計好嘅提示詞同用戶打嘅關鍵詞夾埋，當做 `messages` 參數發出去。咪忘記將你條 DeepSeek API Key 塞入 `Authorization` header 啊。
    *   收到 DeepSeek 嘅回應之後，抽返個測算結果出嚟，然後傳返畀小程序。
    
    以下係一個 Node.js 後端服務嘅超簡化範例：
    ```javascript
    // 假設你用 Node.js 同 Express
    const express = require('express');
    const axios = require('axios');
    const app = express();
    app.use(express.json());
    
    const DEEPSEEK_API_KEY = 'YOUR_DEEPSEEK_API_KEY'; // 記得替換！
    
    app.post('/api/calculate', async (req, res) => {
      const { keywords } = req.body;
      if (!keywords) {
        return res.status(400).send('Missing keywords');
      }
    
      try {
        const prompt = `你係一個專業嘅性格分析師，請根據用戶提供嘅以下幾個關鍵詞，分析佢嘅性格特徵，並建議佢代表一種最符合嘅香港地道小食，解釋點解。請以輕鬆幽默嘅語氣回應，並確保答案唔會超過 100 字。\n用戶提供嘅關鍵詞：${keywords}`; 
        
        const deepseekRes = await axios.post('https://api.deepseek.com/chat/completions', {
          model: 'deepseek-chat', // 或者你用嘅其他模型
          messages: [{ role: 'user', content: prompt }],
          stream: false
        }, {
          headers: {
            'Content-Type': 'application/json',
            'Authorization': `Bearer ${DEEPSEEK_API_KEY}`
          }
        });
        
        const result = deepseekRes.data.choices[0].message.content;
        res.json({ success: true, data: result });

      } catch (error) {
        console.error('DeepSeek API error:', error.response ? error.response.data : error.message);
        res.status(500).json({ success: false, message: '測算失敗，請稍後再試。' });
      }
    });
    
    const PORT = process.env.PORT || 3000;
    app.listen(PORT, () => {
      console.log(`Server running on port ${PORT}`);
    });
    ```

3.  **搞掂網絡請求設定**：喺微信開發者工具入面，打開「項目設置」 -> 「本地設置」，將你個後端服務嘅域名加到「開發環境不校驗合法域名、web-view（業務域名）、TLS 版本以及 HTTPS 證書」同「request 合法域名」嗰度，咁樣測試嗰陣先冇問題。

## 常見問題

*   **我條 DeepSeek API Key 安全唔安全㗎？**
    *   老實講，千祈咪直接喺小程序前端代碼度用你條 API Key！一定要經你自己個後端服務轉發請求。將 Key 穩陣咁擺喺後端，等後端去叫 DeepSeek API 就最好。咁樣先可以保證你條 Key 唔會畀人睇到。

*   **DeepSeek API 有冇話請求次數上限㗎？**
    *   梗係有啦。DeepSeek 會限住你每分鐘可以發幾多次請求 (RPM) 同埋每分鐘用幾多 Token (TPM)。如果你個小程序好多人用，後端可能就要諗吓點樣排隊、做緩存，或者直接升級 DeepSeek 嘅服務方案嚟應付。不過，一開始開發嗰陣，通常都唔使擔心呢個問題嘅。

*   **小程序上架同審核要留意啲乜？**
    *   確保你個小程序嘅內容係符合微信平台規矩㗎，尤其係 AI 生成嘅內容，敏感嘢一定要避開。上架前要狂測，確保功能穩陣，用戶用得開心。遞交審核嗰陣，功能點樣用、操作指引都要寫到清清楚楚，咁會審得快啲。

*   **錢嘅方面點樣計數？**
    *   DeepSeek API 係用幾多畀幾多錢嘅，記得睇清楚佢嘅收費表。另外，你個後端服務（租雲服務器嗰啲）都會有相關費用。最好預先定個預算，再監控吓 API 實際用咗幾多錢。
