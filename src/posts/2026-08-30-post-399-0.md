## 實戰教學：三步搞掂 DeepSeek 專屬介面

嚟到重頭戲！跟住我步驟，好快你就會擁有自己 DeepSeek 介面。**係咪好期待呢？**

### 第一步：Fork Next-Web 專案到你嘅 GitHub

首先，打開瀏覽器，去 Next-Web GitHub 專案頁面：`https://github.com/Yidadaa/ChatGPT-Next-Web` (雖叫 ChatGPT-Next-Web，但完美支援 DeepSeek 㗎！)。

頁面右上角見到「Fork」按鈕，點擊佢，複製專案到你 GitHub 賬號底下。咁做為咗你喺 Vercel 部署時有自己版本，將來改都唔影響原專案，夠晒自由！

### 第二步：利用 Vercel 快速部署

成功 Fork 專案後，Vercel 舞台等緊你。登入 Vercel 賬號 (用 GitHub 登入真係方便好多！)。

1.  喺 Vercel 介面，點擊「Add New」->「Project」。
2.  佢會叫你「Import Git Repository」，揀返你啱啱 Fork 嘅 `ChatGPT-Next-Web` 專案就得。
3.  嚟到「Configure Project」畫面，大佬，呢度真係超級重要！就係要**設定環境變數 (Environment Variables)**。
    *   點擊「Environment Variables」區塊，新增變數。
    *   變數名 (Name) 輸入：`DEEPSEEK_API_KEY`
    *   變數值 (Value) 輸入：你喺 DeepSeek 官網拎到嘅 API Key。
    *   （選填）想為介面設密碼，額外新增變數：`CODE`，變數值就係你自訂密碼 (例如：`your_secret_password`)。咁樣，其他人就唔可以隨便用你介面，私隱度更高！
4.  設定好晒，點擊「Deploy」。Vercel 會自動幫你編譯同部署專案。呢個過程幾分鐘，部署頁面睇到即時進度。

![DeepSeek 模型運算伺服器架構](https://images.unsplash.com/photo-1518770660439-4636190af475?q=80&w=800&auto=format&fit=crop)

當你見到「Congratulations! Your Project has been successfully deployed.」呢句，恭喜你，大功告成啦！Vercel 會自動畀個 `vercel.app` 域名你，一點擊就可以即刻用你 DeepSeek 介面！

### 第三步：配置 DeepSeek API Key 同介面設定

進入部署好嘅 Next-Web 介面後，可能要輸入設定嘅密碼 (冇設就直接入去)。

1.  介面左下角見到齒輪狀「設定」圖示，點擊佢。
2.  設定頁面見到「API Key」輸入框。雖喺 Vercel 已設 `DEEPSEEK_API_KEY`，但想臨時切換或測試其他 Key，都可在這裡輸入。
3.  再碌落去，見到「模型選擇 (Model)」選項。揀 `DeepSeek`，然後會見到可揀 `DeepSeek-Chat` 或其他相關模型。記住揀啱 DeepSeek 模型喎！
4.  你仲可在設定頁面調整其他嘢，例如：語言、主題（深色/淺色）、字體大小，甚至自訂提示詞等等。我測試時發現，善用提示詞庫，對於日常工作重複性高嘅查詢特別有用，可大大提高效率，**係咪好正？**

## 進階優化：讓你的 DeepSeek 介面更專業

搞掂部署後，想進一步提升體驗，可考慮呢幾點：

*   **自訂域名**：Vercel 支援綁定你自訂域名。如果你有自己網域名稱，可在 Vercel 專案設定入面，將 `vercel.app` 域名替換成你專屬域名，咁睇落去就更專業啦！
*   **多模型切換**：Next-Web 本身支援多種模型。如果你有其他模型 API Key (例如 OpenAI GPT-4、Claude 3)，都可在環境變數入面新增對應 Key (例如 `OPENAI_API_KEY`)，然後喺介面內輕鬆切換。
*   **提示詞庫管理**：花啲時間建立個人化提示詞庫，將常用、高效嘅提示詞儲存起嚟，每次用都唔使由頭打過，大大節省時間，**簡直係懶人福音！**

## 常見問題 (FAQ)

*   **Q1：部署失敗點算？**
    *   **A1：** 通常 Vercel 環境變數設錯，或 GitHub 專案同步問題。你可以睇 Vercel 部署日誌 (Logs) 有冇錯誤。最緊要確認 `DEEPSEEK_API_KEY` 正確無誤，冇多餘空格或字元。
*   **Q2：DeepSeek API Key 點解無效？**
    *   **A2：** 首先睇 Key 係咪喺 DeepSeek 官網生成，係咪仲有效。然後檢查介面設定 DeepSeek 模型有冇揀啱。有時 DeepSeek 會更新 API 接口，留意 Next-Web 專案更新日誌，確保你嘅 Fork 係最新版本啦。
*   **Q3：介面反應好慢點算？**
    *   **A3：** AI 模型反應速度受多種因素影響，包括 DeepSeek 伺服器負載、你網絡速度，同埋你問嘅問題有幾複雜。如果網絡正常，可試切換 DeepSeek 不同模型版本，或精簡提示詞。Vercel 部署地點近你都會有影響，香港用戶用 Vercel 速度通常都幾快。
*   **Q4：費用問題，Next-Web 同 DeepSeek 會唔會好貴？**
    *   **A4：** Next-Web 本身開源免費，部署 Vercel 亦有充足免費額度畀個人用戶、中小企用。主要費用來源係 DeepSeek API 使用。DeepSeek 以相對經濟價格聞名，按你實際用嘅 Token 數量收費。一般日常使用，費用好低，可在 DeepSeek 後台查看詳細收費標準同用量統計。
