### 第一步：攞到「案發現場」嘅手機截圖同 HTML

首先，我哋要扮成「手機」去睇你個網站，然後將佢喺手機上面嘅樣衰樣（或者靚仔樣，咳咳）截圖同埋拎佢嘅 HTML 內容出嚟。呢度，神器就係 **Headless Browser**，好似 Playwright 或者 Puppeteer 咁。

睇下呢段 Python + Playwright 嘅 Code，超簡單就搞掂截圖同抓 HTML：

```python
from playwright.sync_api import sync_playwright

def capture_mobile_view(url, output_html_path="mobile_page.html", output_screenshot_path="mobile_screenshot.png"):
    with sync_playwright() as p:
        browser = p.chromium.launch()
        context = browser.new_context(
            user_agent="Mozilla/5.0 (iPhone; CPU iPhone OS 13_5 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/13.1.1 Mobile/15E148 Safari/604.1",
            viewport={'width': 375, 'height': 812}, # iPhone X 尺寸
            is_mobile=True
        )
        page = context.new_page()
        page.goto(url)
        page.screenshot(path=output_screenshot_path)
        html_content = page.content()
        with open(output_html_path, "w", encoding="utf-8") as f:
            f.write(html_content)
        browser.close()
    print(f"已捕捉 {url} 的移動端視圖，保存至 {output_html_path} 及 {output_screenshot_path}")

# 假設你要檢查的網頁是 https://example.com
# capture_mobile_view("https://example.com")
```

跑完上面段 Code，你手頭上就會有 `mobile_page.html` 同埋 `mobile_screenshot.png` 兩份嘢。記住喇，呢兩份就係 DeepSeek AI 大顯身手嘅「原始證據」！如果你有好多頁要查，咪整個 List 俾佢，自動波批量處理，慳水慳力！

### 第二步：DeepSeek AI 化身「福爾摩斯」，分析問題兼開藥方

攞到晒 HTML 同埋截圖之後，下一步就係將佢哋「餵」俾 DeepSeek AI。話說 DeepSeek API 依家仲未識睇圖（但遲早會㗎嘛！），所以你就要做個小小嘅「翻譯官」，將喺 `mobile_screenshot.png` 度見到嘅「碎版」慘況，用文字精準咁描述出嚟，再連同 HTML 代碼一齊傳俾 DeepSeek。

呢度係一個 DeepSeek API 嘅 Python 呼叫範例，包你一睇就明：

```python
from deepseek import DeepSeek

def analyze_and_suggest_fix(html_content, observed_issues):
    deepseek_api_key = "YOUR_DEEPSEEK_API_KEY" # 記得替換成你嘅 API Key
    deepseek_client = DeepSeek(api_key=deepseek_api_key)

    prompt = f"""分析以下移動端網頁的 HTML 代碼，並根據觀察到的問題提供具體修復建議。
網頁 HTML 代碼：
{html_content}

觀察到的問題 (來自截圖分析)：
{observed_issues}

請以前端工程師的身份，詳細指出導致碎版問題的 CSS 或 HTML 錯誤，並提供清晰、可直接應用的 CSS/HTML 修改方案或建議，例如調整 `display`、`flex`、`grid`、`width`、`media queries` 等。
"""

    response = deepseek_client.chat.completions.create(
        model="deepseek-chat", # 或其他最新模型
        messages=[
            {"role": "user", "content": prompt}
        ],
        max_tokens=1000
    )
    return response.choices[0].message.content
```
