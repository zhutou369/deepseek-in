## 開工前準備：環境設定同資料執位

喂，萬事俱備，只欠東風！想 DeepSeek 幫你報價，首先要準備好「東風」——即係你嘅報價數據同埋開發環境。呢步係成個系統嘅地基嚟㗎！

1.  **資料收集同標準化**：呢個係最最最重要嘅一步。收集所有你公司嘅報價相關資料，包括：
    *   **基本運費**：按地區、距離、車型（例如 5.5 噸車、9 噸車）、時段（平日、假日、夜間）等嘅收費標準。
    *   **物件清單同計費**：常見家俬電器（雪櫃、洗衣機、床架）嘅拆裝、搬運難度評估同對應收費。
    *   **附加服務**：樓梯費（按層數、每層件數計）、停車場費、隧道費、打包費、超時等候費、特別物品（例如鋼琴、魚缸）嘅附加費。

## 第一步：建立你嘅 RAG 知識庫

RAG 呢個嘢，核心就係將你啲報價資料變做 AI 識睇嘅「知識」。

1.  **文本切割同向量化 (Chunking & Vectorization)**：將你嘅結構化數據轉換成易於檢索嘅文本片段，然後用向量 embedding 模型將佢哋轉化為數值向量。DeepSeek 自己有 Embedding 模型，你亦可以用 `bge-large-zh` 呢啲開源嘅。
    *   例如，一個報價條目：「5.5 噸貨車，新界區內，$500 起」，就會被轉換成一個獨特嘅向量。

2.  **建立向量資料庫 (Vector Database)**：將所有向量儲存到向量資料庫中，例如 ChromaDB、FAISS 或者 PGVector。呢個資料庫會幫你超快咁搵到同客仔需求相關嘅報價規則。

    ```python
    # 示例程式碼片段：使用 LangChain 與 ChromaDB 建立 RAG 知識庫
    from langchain_community.embeddings import DeepSeekEmbeddings
    from langchain_community.vectorstores import Chroma
    from langchain.text_splitter import RecursiveCharacterTextSplitter
    import pandas as pd

    # 讀取你的報價數據
    df = pd.read_csv('your_pricing_data.csv')
    documents = []
    for index, row in df.iterrows():
        # 將每一行數據轉化為一個文本描述
        doc_content = f"""
        服務類型: {row['service_type']}
        車型: {row['vehicle_type']}
        起點: {row['origin_district']}
        終點: {row['destination_district']}
        基本費用: {row['base_price']} HKD
        每層樓梯費: {row['stair_fee_per_floor']} HKD
        額外物品: {row['extra_item_price']}
        """
        documents.append(doc_content)

    # 文本切割
    text_splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=100)
    texts = text_splitter.create_documents(documents)

    # 向量化並儲存到 ChromaDB
    embeddings = DeepSeekEmbeddings(deepseek_api_key="YOUR_DEEPSEEK_API_KEY")
    vectordb = Chroma.from_documents(documents=texts, embedding=embeddings, persist_directory="./chroma_db")
    vectordb.persist()
    print("知識庫建立成功！")
    ```

## 第二步：DeepSeek 模型點用？接口點搞？

DeepSeek 模型本身已經好勁，但想佢報價更貼近你公司實際情況，可以小修小改（或者更簡單粗暴，直接寫好個提示詞就得啦）。

1.  **提示詞工程 (Prompt Engineering)**：呢個係核心！你需要設計一個清晰、具體嘅提示詞 (Prompt)，指示 DeepSeek 點樣根據客仔嘅輸入同埋 RAG 搵到嘅資料去生成報價單。提示詞入面最好有齊：
    *   **角色設定**：例如「你係一間香港搬屋公司嘅智能報價專員。」
    *   **任務指令**：清晰說明要生成報價單，仲要列明必須包含嘅項目（例如：基本費、樓梯費、隧道費、總計）。
    *   **格式要求**：報價單出咩格式都要講明，例如 Markdown 表格就最方便睇。
    *   **約束條件**：強調一定要根據提供嘅知識庫資料報價，唔可以亂咁作價㗎！

2.  **API 接口設定**：用 Python 或者其他程式語言調用 DeepSeek API。如果用 Ollama 部署 DeepSeek 模型，咁就係調用本地端點啦。

    ```python
    import requests
    import json

    DEEPSEEK_API_KEY = "YOUR_DEEPSEEK_API_KEY"
    DEEPSEEK_API_URL = "https://api.deepseek.com/chat/completions" # 或者你嘅本地 Ollama 端點

    def get_deepseek_response(prompt_messages):
        headers = {
            "Content-Type": "application/json",
            "Authorization": f"Bearer {DEEPSEEK_API_KEY}"
        }
        payload = {
            "model": "deepseek-chat", # 或 deepseek-v2, deepseek-coder 等
            "messages": prompt_messages,
            "stream": False
        }
        try:
            response = requests.post(DEEPSEEK_API_URL, headers=headers, json=payload)
            response.raise_for_status()
            return response.json()['choices'][0]['message']['content']
        except requests.exceptions.RequestException as e:
            print(f"API 請求失敗: {e}")
            return None
    ```

## 第三步：實戰出報價單！

將 RAG 同 DeepSeek 合體，處理客仔查詢，秒生成最終報價單！

1.  **接收客仔需求**：例如一個 Web 表單或客服介面接收客仔輸入，如：「我要從灣仔莊士敦道 212 號 5 樓搬到九龍城太子道西 368 號 2 樓，有 30 個標準箱、一個雙人床、一個雪櫃。需要拆裝床架。」

2.  **RAG 搵料**：根據客仔嘅輸入，從向量資料庫中檢索出最相關嘅報價規則、地區收費、物品清單等資訊。例如，搵到「灣仔至九龍城基本運費」、「雙人床拆裝費」、「雪櫃搬運費」、「樓梯費每層 $50」等。

3.  **構建最終 Prompt 並調用 DeepSeek**：將客仔需求、搵到嘅知識、以及你預設嘅提示詞結合起來，發送俾 DeepSeek 模型。

    ```python
    # 繼續上面的程式碼
    from langchain_community.embeddings import DeepSeekEmbeddings
    from langchain_community.vectorstores import Chroma

    # 假設知識庫已經建立並持久化
    embeddings = DeepSeekEmbeddings(deepseek_api_key="YOUR_DEEPSEEK_API_KEY")
    vectordb = Chroma(persist_directory="./chroma_db", embedding_function=embeddings)

    def generate_quote(customer_request):
        # 1. 檢索相關知識
        relevant_docs = vectordb.similarity_search(customer_request, k=5) # 檢索最相關的 5 條記錄
        knowledge_context = "\n".join([doc.page_content for doc in relevant_docs])

        # 2. 構建 DeepSeek 提示詞
        system_message = {
            "role": "system",
            "content": (
                "你係一間香港專業搬屋公司嘅智能報價專員，請根據客戶要求同埋提供嘅報價知識庫，"\
                "生成一份詳細、透明且易於理解嘅報價單。報價單必須包含以下項目：基本運費、"\
                "樓梯費（如適用）、附加服務費（如拆裝、特別物品）、總計。請以 Markdown 表格形式輸出。"\
                "如果某項費用不適用，請顯示為 0 HKD。所有計算必須基於提供嘅知識庫資料。")
        }

        user_message = {
            "role": "user",
            "content": (
                f"客戶需求: {customer_request}\n\n"
                f"報價知識庫:\n{knowledge_context}\n\n"
                "請生成報價單。")
        }

        response_content = get_deepseek_response([system_message, user_message])
        return response_content

    # 測試一下！
    customer_input = "我由灣仔莊士敦道 212 號 5 樓搬到九龍城太子道西 368 號 2 樓，有 30 個標準箱、一個雙人床、一個雪櫃。需要拆裝床架。"
    quote_output = generate_quote(customer_input)
    print(quote_output)
    ```
