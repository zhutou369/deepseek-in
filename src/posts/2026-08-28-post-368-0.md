### 實戰教學：三步搞掂客戶溝通與風格提煉

這次我們主要會用 DeepSeek Chat 的網頁版（或者通過其 API 接口），操作步驟超簡單，就算你是 AI 小白也能秒懂，輕鬆上手。

#### 第一步：準備好你的客戶資料

首先，你需要把所有跟客戶溝通的內容都收集齊。這些資料可以是：

*   **第一次諮詢筆記：** 客戶對設計的初步想法、預算、時間表之類的。
*   **聊天記錄：** 你跟客戶之間的郵件往來、會議筆記，甚至是即時通訊軟件的對話截圖（記住，要確保私隱並得到客戶同意哦！）。
*   **參考圖片描述：** 如果客戶發了參考圖，記得把他們對圖片的描述和感受也記錄下來。
*   **生活習慣：** 客戶的家庭成員、職業、興趣、平時生活模式等等，這些都是發現設計風格的關鍵線索！

把這些零碎的資訊整理成一份純文字文件，然後統統丟給 DeepSeek，讓它讀個痛快！

#### 第二步：DeepSeek 提示詞（Prompt）魔法

這一步是重中之重！它決定了 DeepSeek 能多精準地理解你的需求。下面我給你一個提示詞範例，你可以根據實際情況修改調整：

```
你係一位經驗豐富嘅室內設計助理，專門幫設計師分析客戶需求。我會俾你一份客戶嘅溝通紀錄同要求。請你幫我：

1.  **提煉核心設計風格關鍵字：** 從對話中抽離出描述風格嘅詞彙，例如「簡約」、「現代」、「溫馨」、「工業風」、「北歐風」、「豪華」等。如果冇明確提及，請根據佢哋嘅偏好同生活習慣推斷。提供至少 5 個關鍵字。
2.  **總結客戶嘅核心需求：** 列出客戶對空間功能、材料偏好、顏色運用、特殊要求等最重要嘅 3-5 個需求點。
3.  **建議一份 Mood Board 嘅元素清單：** 根據提煉出嚟嘅風格同需求，建議至少 5-8 個可以放入 Mood Board（情緒板）嘅元素，例如： specific material textures (木紋、水泥、大理石)、color palettes (柔和色調、撞色)、furniture styles (流線型、復古)、lighting types (間接照明、軌道燈) 或者 specific decorative items (綠植、藝術品)。
4.  **提供潛在嘅設計挑戰或衝突點：** 如果對話中有任何自相矛盾或者難以平衡嘅要求，請指出並提出點樣同客戶進一步確認嘅建議。

以下係客戶資料：

[貼上你整理好嘅客戶溝通內容同要求，例如：]

"客戶：陳先生夫婦，有個5歲小朋友。想將將軍澳個新單位裝修。老婆想要個開放式廚房，因為佢鐘意煮嘢食，可以邊煮邊睇住小朋友。先生就想要一個可以放大量漫畫同模型嘅地方，佢話一定要有自己嘅私人空間。兩個人都強調要「實用」，但又希望有「高級感」，唔想太「普通」。佢哋話鍾意淺色系，尤其係米白同淺灰。唔鐘意太複雜嘅線條，最好係簡簡單單、望落舒服。預算方面佢哋都算充足，但唔想做啲華而不實嘅嘢。參考圖片俾咗幾張日式無印良品風同輕奢風嘅客廳圖片。"
```

**Q1: DeepSeek 安全嗎？會不會洩露客戶私隱？**
