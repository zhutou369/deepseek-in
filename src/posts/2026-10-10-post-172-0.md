### 步驟 1：申請 DeepSeek API Key 同環境設定

首先，你要去 [DeepSeek AI 平台](https://platform.deepseek.com/) 申請個 API Key。搞掂咗之後，我哋就會用 Python 嚟 Call API。記得要裝咗 `openai` Python library 先好喎，因為 DeepSeek API 同 OpenAI 格式係兼容嘅。如果仲未裝，快啲用 `pip install openai` 搞掂佢啦！

```python
import os
from openai import OpenAI

# 設定 DeepSeek API Key
os.environ["DEEPSEEK_API_KEY"] = "你嘅API_KEY"

client = OpenAI(
    api_key=os.environ.get("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com/v1", # DeepSeek API 基礎 URL
)
```

### 步驟 2：粵語音頻轉錄成初步文本

為咗專心試 DeepSeek V2 嘅翻譯功力，我哋就當已經有個粵語錄音檔（好似 MP3、WAV 咁）轉咗做文字稿先。呢步你可以用任何語音轉文本服務，好似 OpenAI Whisper API 或者其他第三方程式都得。假設我哋手頭上已經有段粵語原文，講緊香港飲食文化嘅嘢：`粵語原文（初步轉錄）: "喂，最近有無去旺角食嘢啊？嗰度有間茶餐廳個蛋撻好好食㗎，皮脆餡滑，一咬落去就知係香港地道風味。"`

### 步驟 3：呼叫 DeepSeek V2 API 進行繁體中文翻譯

而家，我哋就用 DeepSeek V2 API，將頭先段粵語文字稿翻成超精準嘅香港繁體中文。我哋會特別同佢講，一定要出香港繁體中文，確保夠地道！

```python
# 假設已轉錄嘅粵語文本
cantonese_text = "喂，最近有無去旺角食嘢啊？嗰度有間茶餐廳個蛋撻好好食㗎，皮脆餡滑，一咬落去就知係香港地道風味。"

# 準備 DeepSeek API 嘅請求
response = client.chat.completions.create(
    model="deepseek-v2", # 指定 DeepSeek V2 模型
    messages=[
        {"role": "system", "content": "你係一個專業嘅香港翻譯員，請將以下內容翻譯成最地道、最準確嘅香港繁體中文。"},
        {"role": "user", "content": f"請翻譯以下粵語：{cantonese_text}"}
    ],
    temperature=0.7, # 控制創意度
    max_tokens=150
)

translated_text = response.choices[0].message.content
print(f"翻譯結果：{translated_text}")
```

## DeepSeek V2 音頻翻譯常見問題（FAQ）

### Q1: DeepSeek V2 係咪真係識得粵語？

DeepSeek V2 唔係天生就識粵語，但佢作為一個超級大嘅語言模型，食咗好多唔同語言嘅數據訓練，所以佢嘅語言理解同生成能力好勁，對粵語都算有一定認識。我哋主要係用佢喺文字層面，將「粵語文字變香港繁體中文」嚟翻譯同執靚，唔係直接聽粵語錄音。佢會盡力跟足你指令，出返啱香港人語境嘅繁體中文㗎。

### Q2: 本地部署 DeepSeek V2 有無可能？

DeepSeek V2 個完整模型好巨型，通常經 API 用會方便好多。**但如果**你對數據私隱或者網絡速度有極高要求，又或者你夠料（例如有好多勁 GPU），咁就可以考慮用 `vLLM` 或者好似 `Ollama` 呢啲開源方案，試下自己部署 DeepSeek 嘅其他開源版或者輕量化模型，或者將 DeepSeek V2 做量化（quantization）之後再部署。不過講到底，想做到同 API 版一樣咁勁，真係要使好多錢買硬件同埋要識好多專業嘢。

### Q3: 點樣可以優化翻譯結果？

想 translation 結果好啲？有幾個貼士你可以試下：
1.  `system` prompt 寫清楚啲：直接同 DeepSeek V2 講，佢係「專業嘅香港翻譯員」，要佢出「最地道、最準確嘅香港繁體中文」。
2.  畀多啲上下文：如果啲內容有行內術語或者專有名詞，可以喺 prompt 度加少少解釋。
3.  Few-shot Learning：即係畀一兩個翻好咗嘅例子佢睇，等佢明你想要咩風格同語氣。
4.  後期執手尾 (Post-processing)：就算係最勁嘅模型，有時都可能要人手執一執，特別係啲關鍵字眼。
