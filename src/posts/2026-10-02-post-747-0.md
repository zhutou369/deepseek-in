## 準備工作：環境設定與模型部署

想讓 DeepSeek AI 在你的電腦上動起來，硬件方面還是有點要求的，主要是顯卡要夠勁兒。建議用 NVIDIA RTX 30 系列或更高級的，最好有 12GB 或更多的顯存（VRAM）。你可以用一台專門的電腦，或者就是你平時的工作站也行。

### 1. 安裝 vLLM 與相關依賴

首先，Python 3.9 或更高版本，以及 `pip` 包管理器，你得先裝好。然後，我們就能用 pip 來安裝 vLLM。vLLM 是一個又快又好用的模型推理庫，搞定大模型本地部署，效率槓槓的！

```bash
# 確保你的 CUDA 環境已正確配置
pip install vllm
```

### 2. 下載 DeepSeek-V2 模型

你可以從 Hugging Face 下載 DeepSeek-V2 模型。模型文件挺大的，硬碟空間可要備足（幾十 GB 到上百 GB 不等）。

```python
from huggingface_hub import snapshot_download

model_name = "deepseek-ai/DeepSeek-V2"
model_path = "./DeepSeek-V2-local"
snapshot_download(repo_id=model_name, local_dir=model_path, allow_patterns=["*.safetensors", "config.json", "tokenizer.json", "tokenizer_config.json"])
```

### 3. 啟動 vLLM API 服務

下載完畢，就可以啟動 vLLM API 服務了。這會把 DeepSeek-V2 模型載入到顯卡記憶體裡，然後開個本地接口讓你的應用程式調用。

```bash
python -m vllm.entrypoints.api_server \
    --model "./DeepSeek-V2-local" \
    --tensor-parallel-size 1 \
    --port 8000
```

這條指令會啟動一個本地 API 服務，默認在 `http://localhost:8000` 端口監聽請求。`--tensor-parallel-size 1` 代表用一張顯卡，如果你有多張顯卡可以增加這個數值來提升性能。成功啟動後，發個 HTTP 請求就能跟 DeepSeek-V2 對話了，這不比雲服務香？

## 食譜生成核心：提示詞（Prompt）設計

寫好提示詞，是生成高品質食譜的核心。我們要把客戶的詳細資料，有條理地餵給 DeepSeek AI。下面這些是核心要點：

*   **客戶基本資料**：年齡、性別、身高、體重、活動水平（久坐、中等活躍、非常活躍）。
*   **目標**：減脂、增肌、維持體重。
*   **特殊要求**：忌口（例如：花生、海鮮）、過敏（乳糖不耐、麩質）、飲食習慣（素食、彈性素食、生酮）、不喜歡的食材。
*   **餐數與時間**：每天幾餐？是否有加餐需求？
*   **本地化需求**：香港常見食材、烹飪方式、茶餐廳菜式調整等。

### 提示詞範例：

```
請為一位香港客戶制定一個為期一天的減脂增肌食譜。該客戶是一位28歲男性，身高175cm，體重80kg，每週運動5次（中等活躍）。他的目標是減脂同時增肌，每日熱量攝入約為2200卡路里，蛋白質佔比35%，碳水化合物45%，脂肪20%。他對海鮮過敏，不喜歡吃豬肉，但偏好雞胸肉和牛肉。請提供早、午、晚三餐及一次加餐的詳細食譜，包含食材、份量（以常見計量單位表示），並建議簡單的烹飪方式，同時考慮香港本地常見食材的可得性。
```

你可以將上述提示詞通過程式碼發送到你的本地 vLLM API 服務：

```python
import requests
import json

url = "http://localhost:8000/v1/completions"
headers = {"Content-Type": "application/json"}

# 替換成你的實際提示詞
prompt = "請為一位香港客戶制定一個為期一天的減脂增肌食譜..."

data = {
    "model": "deepseek-ai/DeepSeek-V2", # 模型的識別符，可以是本地路徑名
    "prompt": prompt,
    "max_tokens": 1024, # 調整輸出長度
    "temperature": 0.7, # 控制創造性，0.7是個不錯的平衡點
    "top_p": 0.9
}

response = requests.post(url, headers=headers, data=json.dumps(data))

if response.status_code == 200:
    result = response.json()
    generated_text = result['choices'][0']['text']
    print(generated_text)
else:
    print(f"錯誤：{response.status_code}, {response.text}")
```

## 常見問題

### 1. 本地部署會不會很難？我不是 IT 專家怎麼辦？

確實需要一點命令行操作基礎，但跟著這篇教學一步步來，大部分教練都能自己搞定。如果你對命令行指令不太熟，可以找個懂 IT 的朋友幫忙，或者花點時間學學基礎的 Linux/macOS 指令。一旦設定好了，日常使用起來就小菜一碟了。

### 2. 我的顯示卡只有 8GB VRAM 夠用嗎？

對於 DeepSeek-V2 完整版模型來說，8GB 顯存會有點吃力，很可能會報記憶體不足的錯誤。建議至少 12GB。不過 DeepSeek 也有提供更小的量化版本（比如 Q4_K_M），這些版本在顯存小的顯卡上也能跑，只是性能會打折扣。你可以試著下載這些量化模型，然後在啟動 vLLM 時指定它們。

### 3. DeepSeek AI 生成的食譜準確性如何？

AI 生成的食譜是個不錯的開端，但絕對不能完全取代你的專業判斷。模型的數據庫是基於它訓練時的資料，不一定能完全涵蓋最新的營養學研究，或者每個人的身體差異。所以，你作為專業教練的知識和經驗，在審核和調整食譜方面是無可替代的，明白嗎？記住，把它當成超級助手，但它還替代不了你。
