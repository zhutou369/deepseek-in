## 香港稅務局的財務報表要求概覽

喺深入討論DeepSeek之前，我哋首先要了解香港稅務局對公司財務報表嘅基本要求。根據《稅務條例》，所有香港註冊成立嘅有限公司都必須每年向稅務局提交已審計嘅財務報表，以便評定利得稅。主要包括以下幾部分：

*   **綜合損益表 (Consolidated Income Statement / Profit & Loss Account)：** 顯示公司喺某個會計年度內嘅收入、開支同最終盈利或虧損。
*   **綜合財務狀況表 (Consolidated Statement of Financial Position / Balance Sheet)：** 顯示公司喺特定日期嘅資產、負債同股東權益。
*   **現金流量表 (Cash Flow Statement)：** 顯示公司喺某個會計期間內現金嘅流入同流出情況。
*   **股東權益變動表 (Statement of Changes in Equity)：** 記錄股東權益喺報告期內嘅變動。
*   **財務報表附註 (Notes to the Financial Statements)：** 提供額外資訊，解釋財務報表項目嘅細節、會計政策同其他相關資料。

稅務局嘅核心要求係報表必須**真實、公平地反映公司嘅財務狀況**，並且**符合香港會計準則（HKFRS）**。對於中小企嚟講，主要嘅難點通常喺於：

1.  **數據整理：** 大量交易數據需要準確錄入同分類。
2.  **格式合規：** 確保報表項目同格式符合會計準則同稅務局嘅期望。
3.  **附註生成：** 附註部分往往需要專業判斷同標準措辭。
4.  **分析洞察：** 唔單止要提交報表，更重要嘅係從中獲得有價值嘅業務洞察。

## DeepSeek一鍵生成財務報表分析的技術原理

要理解 DeepSeek 如何實現「一鍵生成」，我哋需要從其底層技術原理入手。

### 大型語言模型 (LLM) 的基礎

DeepSeek 屬於 Transformer 架構嘅大型語言模型，透過海量文本數據嘅訓練，學習咗豐富嘅語言模式、世界知識同邏輯推理能力。佢能夠：

*   **理解指令 (Prompt Understanding)：** 將用戶提供嘅自然語言指令（即 Prompt）轉化為模型可以處理嘅內部表示。
*   **上下文推理 (Contextual Reasoning)：** 根據輸入數據同指令，理解其財務意義，例如「收入」代表銷售額、「開支」代表營運成本。
*   **生成響應 (Response Generation)：** 根據理解同推理，生成符合指令要求嘅文本輸出，無論係結構化報表、分析洞察定係總結。

### 數據輸入與前處理

要讓 DeepSeek 進行分析，首先要有數據。中小企通常會從會計軟件（例如 QuickBooks, Xero, MYOB）導出試算表（Trial Balance）或總賬（General Ledger）數據，格式多為 CSV 或 Excel。

1.  **數據標準化：** DeepSeek 或一個前端應用會首先對這些數據進行標準化處理，例如統一科目名稱、處理缺失值、將數字轉換為可計算格式等。
2.  **數據輸入：** 用戶可以選擇直接將 CSV 或 Excel 數據複製粘貼到 DeepSeek 的對話介面，或者通過 API 接口上傳。

### 邏輯判斷與格式生成

呢個係 DeepSeek 嘅核心能力之一。當接收到財務數據同用戶指令後，DeepSeek 會執行以下步驟：

1.  **會計科目映射：** 將輸入數據中嘅會計科目（例如「銀行存款」、「應收賬款」、「銷售收入」）映射到損益表同資產負債表嘅標準會計項目。
2.  **數值計算與彙總：** 根據會計原則，對各科目嘅數值進行彙總，計算出總收入、總開支、淨利潤、總資產、總負債等關鍵指標。
3.  **格式遵循：** 透過精密嘅 Prompt Engineering，指導 DeepSeek 按照香港會計準則（HKFRS）同稅務局要求嘅報表結構（例如先列流動資產、後列非流動資產）來組織輸出。佢甚至可以生成類似表格嘅 Markdown 或 JSON 格式，方便後續處理。

### 分析與洞察輸出

DeepSeek 嘅價值唔止於生成報表，更在於提供初步嘅財務分析。例如，你可以要求佢：

*   計算關鍵財務比率（例如毛利率、淨利率、流動比率、負債權益比）。
*   分析收入或開支嘅增長趨勢。
*   識別異常項目或潛在風險。

```

1.  **綜合損益表 (Consolidated Income Statement / Profit & Loss Account)**
2.  **綜合財務狀況表 (Consolidated Statement of Financial Position / Balance Sheet)**
3.  **財務報表附註 (Notes to the Financial Statements)**：請提供至少三個關鍵附註，例如會計政策摘要、物業、廠房及設備的分析。
4.  **主要財務比率分析 (Key Financial Ratios Analysis)**：計算並簡要解釋毛利率、淨利率、流動比率、負債權益比，並指出任何值得關注的趨勢或異常。

*   **語言：** 必須使用正宗的【香港繁體中文】（zh-HK）。

*   **合規性：** 確保所有會計處理原則符合HKFRS，並且報表結構符合香港稅務局對審計報告附件的慣常要求。
*   **數據來源：** 報表數據將從下方提供。

**公司名稱：** 香港範例有限公司
**會計期間：** 截至2025年12月31日止年度

---
**以下是公司的試算表數據：**
[在此粘貼你從步驟一準備好的財務數據，例如上面的簡化版數據]

```

*   **角色扮演 (Role-playing)：** 將 DeepSeek 設定為「香港持牌會計師」，能引導佢以專業角度思考。
*   **明確目標：** 清晰列出需要生成嘅內容項目。
*   **具體要求：** 強調「香港繁體中文」、「HKFRS」、「稅務局格式」等關鍵詞。
*   **分步指示：** 如果一次性Prompt太複雜，可以分幾次提示，例如先生成損益表，再生成資產負債表。

1.  **輸入數據：** 複製你準備好嘅財務數據，粘貼到 Prompt 中指定嘅位置。

### 面對的挑戰

*   **數據私隱與安全：** 財務數據屬於高度敏感資訊。使用 DeepSeek 等雲端AI服務時，必須仔細評估其數據安全政策，確保符合香港個人資料（私隱）條例，並考慮是否需要在本地部署（On-Premise）或使用私有化模型。

*   **合規性動態：** 香港稅務法規同會計準則可能會隨時更新。DeepSeek 嘅知識庫可能無法即時反映最新變化，需要用戶自行補充最新資訊。
*   **複雜會計處理：** 對於複雜嘅合併報表、特殊交易（例如衍生工具）或稅務籌劃，DeepSeek 嘅能力仍然有限，需要專業會計師介入。
