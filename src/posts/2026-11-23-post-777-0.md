## 開搞前準備：電腦配置和核心軟件

想玩轉本地 AI，首先得把「傢伙」準備好。

### 電腦硬件要求

雖然是本地部署，但電腦性能還是得跟上，不然會卡到哭。下面這些配置，建議你最好有：

*   **處理器 (CPU)**：Intel i5/AMD Ryzen 5 或更高階，核心越多越好，效率槓槓的。
*   **記憶體 (RAM)**：最低 16GB，建議 32GB 或以上，對跑大模型來說，這玩意兒特別重要。
*   **顯示卡 (GPU)**：不一定非要，但如果配備 NVIDIA RTX 30 系列或更高階的顯示卡（比如 8GB 顯存以上），那無論是 Whisper 處理大型模型語音，還是 Ollama 跑 DeepSeek 模型，速度都會快得讓你驚訝。

### 安裝 Ollama

Ollama 簡直就是本地跑 LLM 的神器，安裝超級簡單。咱們這次會用 **Ollama v0.1.30** 或更新版本來做示範。你只需要直奔 Ollama 官網（ollama.ai），扒拉個符合你系統（macOS, Linux, Windows）的版本下來，然後按指示一步步裝就行。

裝好後，打開終端機或者命令提示字元，敲 `ollama --version`，如果看到版本號，那就說明你搞定了。

### 安裝 Whisper 相關套件

Whisper 是 OpenAI 家的語音轉文字模型，各種語言表現都超棒。咱們會用 Python 來調用它。確保你機器上裝了 Python 3.8 以上的版本，然後敲下面這行指令，把需要的庫都裝上：

`pip install transformers torchaudio soundfile`

簡單說，`transformers` 是用來載入 Whisper 模型的，`torchaudio` 負責處理音頻，`soundfile` 嘛，就負責讀取音頻文件。

## 三步實戰：搭建你的離線語音助手

工具都備齊了，那咱們就直接開幹！

### 第一步：下載並執行 DeepSeek LLM 模型

首先，得用 Ollama 下載一個 DeepSeek 模型。DeepSeek 推出了 DeepSeek-LLM (通用語言模型) 和 DeepSeek-Coder (程式碼模型)。基於咱們語音助手的通用性，可以先搞個 DeepSeek-LLM 的指示調優版本試試水。在終端機輸入：

`ollama run deepseek-llm:7b-chat`

Ollama 會自動幫你下載這個 7B 參數的模型（大概 4GB 左右），然後直接進入交互模式。你可以試著跟它簡單聊幾句，例如：「你好，介紹一下香港。」看看它表現怎麼樣。

### 第二步：整合 Whisper 語音轉文字

這一步就是把你的語音輸入轉換成文字，再丟給 DeepSeek 模型。接下來，咱們得寫個簡單的 Python 腳本：

1.  **錄音功能**：用 `sounddevice` 或者 `pyaudio` 庫把用戶語音錄成 `.wav` 文件。這裡為了簡化，咱們先假設你已經有錄好的語音文件。
2.  **Whisper 轉錄**：使用 `transformers` 庫載入 Whisper 模型，把 `.wav` 文件轉成文字。

比如，你可以先載入 `openai/whisper-base` 這個模型，它在 CPU 上跑得不算慢，準確度也還行。

```python
# 注意！這只是個示例代碼，跑不起來的，別直接複製貼上哦！
from transformers import pipeline
import soundfile as sf

audio_file = "your_recording.wav"

pipeline = pipeline("automatic-speech-recognition", model="openai/whisper-base")
text = pipeline(audio_file)["text"]
print(f"你說的是：{text}")
```

### 第三步：閉環交互：語音輸入、AI處理、文字輸出

把前面兩步結合起來，再加入 Ollama 的交互，這樣一個完整的語音助手閉環就形成了。整體流程是這樣的：

1.  **錄製語音**：用麥克風錄下用戶的問題。
2.  **Whisper 轉文字**：把錄音丟給 Whisper 模型，得到文字輸入。
3.  **Ollama 呼叫 DeepSeek**：把文字輸入傳給 Ollama 運行的 DeepSeek 模型。
4.  **獲取回應**：DeepSeek 模型吐出文字回應。
5.  **顯示回應**：把回應顯示在螢幕上（甚至可以加上文字轉語音，讓助手「開口說話」）。

你需要一個 Python 腳本，把 `sounddevice` (錄音)、`transformers` (Whisper) 和一個簡單的 HTTP 請求庫 (比如 `requests`) 串起來，跟 Ollama 的 API 對話。Ollama 在本地會提供一個 API 接口，可以讓其他程式呼叫。

## 優化小撇步與進階玩法

*   **提示詞優化**： DeepSeek 模型對提示詞（Prompt）可是相當敏感的。多嘗試不同問法、加點角色設定（Persona），或者要求它輸出特定格式的內容，這樣回答質量會飆升。比如，要求 DeepSeek-Coder 幫你生成 Python 程式碼時，可以明確指定函式名稱、輸入參數和輸出格式。
*   **模型選擇**：Ollama 上有好多不同版本的 DeepSeek 模型，例如 DeepSeek-Coder 專為程式開發設計，DeepSeek-LLM 更適合日常對話。根據你的需求，選最適合的模型，甚至可以下載其他開源模型來試試看。
*   **語音輸出 (TTS)**：要真正搞定語音交互，文字轉語音（Text-to-Speech, TTS）是必不可少的一環。你可以整合像 `gtts` (Google Text-to-Speech) 或其他開源 TTS 引擎（例如 Bark, VITS），把 DeepSeek 的文字回應轉換成語音輸出。這樣你的助手就能「開口說話」了！

## 常見問題 (FAQ)

### Q1: 我的顯示卡不夠力，咋辦？

如果你的顯示卡（GPU）顯存不足或者沒有獨立顯示卡，Ollama 和 Whisper 都會自動切換到 CPU 運行。雖然速度會慢很多，但還是能正常用。我測試時發現，如果錄音環境嘈雜，Whisper 的準確度會大打折扣，所以我會建議大家盡量在安靜環境下使用，或者考慮買個指向性麥克風。建議選擇參數小一點的模型，例如 DeepSeek-LLM 1.3B 或 7B，以及 Whisper `base` 或 `small` 模型，這樣能減輕 CPU 負擔。

### Q2: Ollama 怎麼更新模型？

Ollama 更新或替換模型，指令超簡單。如果 DeepSeek-LLM 有新版本發布，你只需要執行 `ollama pull deepseek-llm:7b-chat`，Ollama 就會自動下載最新版本。如果要刪掉舊模型，可以用 `ollama rm deepseek-llm:7b-chat`。

### Q3: 語音識別不準？

語音識別（ASR）的準確度會被很多因素影響，比如錄音質量、背景噪音、麥克風性能和模型大小。如果 Whisper 識別不準，你可以試試：

*   **提升錄音品質**：換個好點的麥克風，在安靜環境下錄音。
*   **選用更大的 Whisper 模型**：比如 `whisper-medium` 或 `whisper-large-v3`，它們準確度更高，但電腦會比較吃力。
*   **多語言模型**：確保你用的 Whisper 模型支援廣東話或你說的語言。
