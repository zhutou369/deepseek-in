**三步搞掂實戰教學**
今次我哋就用 Python 3.9 同 Flask 框架做個示範，包你一學就識！

### 第一步：搞掂 DeepSeek API Key 同 Slack App

1.  **DeepSeek API Key：** 先去 `developer.deepseek.com` 申請個 API Key，記得收好啊！
2.  **Slack App：** 再去 `api.slack.com/apps` 整個 App 出嚟。
    *   記得加 `chat:write`, `commands` 權限。
    *   裝好 App，然後拎到「Bot User OAuth Token」。
    *   啟用「Interactivity」後，將 Request URL 指向你伺服器個 endpoint（例如 `https://your-domain.com/slack/events`）。

### 第二步：起個機械人伺服器仔

`app.py` 嘅核心代碼長咁樣：
```python
import os
from flask import Flask, request, jsonify
from deepseek import Deepseek
from dotenv import load_dotenv

load_dotenv()
app = Flask(__name__)
deepseek_client = Deepseek(api_key=os.getenv("DEEPSEEK_API_KEY"))

@app.route("/slack/events", methods=["POST"])
def slack_events():
    text = request.form.get("text")
    if not text: return jsonify({"text": "請提供工單內容。"})
    
    prompt = f"請將以下工單內容總結為少於100字嘅重點摘要，並指出核心問題：\n\n{text}"
    try:
        res = deepseek_client.chat.completions.create(
            model="deepseek-chat", messages=[{"role": "user", "content": prompt}], temperature=0.7, max_tokens=200
        )
        summary = res.choices[0].message.content
        # 實際應用中建議異步發送回 Slack，體驗會更好！
        return jsonify({"text": f"工單摘要：{summary}"}) 
    except Exception as e:
        print(f"DeepSeek API 錯誤: {e}")
        return jsonify({"text": "AI 處理摘要出錯。"})

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```
建個 `.env` 檔案嚟存 API Key。跑起 `app.py`，再用 ngrok 搞掂內網穿透就得啦。

## 常見問題 Q&A

**Q1：機械人收唔到 Slack 訊息點搞？**
A：檢查下 Slack App 個「Request URL」係咪填啱咗（特別係 ngrok URL 會變架！），同埋睇下「Interactivity」有冇開到。

**Q2：DeepSeek 總結結果有時唔太穩定？**
A：我自己實測嗰陣發現，降低 `temperature` 參數（例如 `0.1-0.5`）會令結果穩好多。當然，優化提示詞都係關鍵，可以多試幾種寫法！

**Q3：有敏感資訊要處理點算？**
A：如果係好敏感嘅資料，最好先脫敏處理，或者直接考慮私有化部署。呢啲要睇你公司有冇特別嘅合規要求喇。
