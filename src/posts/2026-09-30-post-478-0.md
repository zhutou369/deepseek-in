## 準備工作：賬號與 API 設定
要開始用 DeepSeek V2 搞自動化分析，我哋得先搭好基本框架。

**第一步：申請 DeepSeek API Key，準備開發環境**
你需要去 DeepSeek 官網搞個 API Key，這是你調用模型服務的「通行證」。對於香港中小企來講，如果你對數據私隱比較敏感，可以考慮私有化部署，把 DeepSeek 的開源模型跑在自己服務器上。但對大部分新手來說，直接用它的雲端 API 會方便很多。

首先，確保你的開發環境裝了 Python 3.8 或以上版本。然後，安裝 DeepSeek 的 Python SDK：

```bash
pip install deepseek-llm-sdk
```

安裝完畢後，你就可以在 Python 代碼裡設定你的 API Key 了：

```python
from deepseek import DeepSeek

api_key = "YOUR_DEEPSEEK_API_KEY" # 請替換成你自己的 API Key
client = DeepSeek(api_key=api_key)
```

## 實戰教學：自動分析財報數據
財報分析是量化交易的基礎，但傳統 PDF 格式的財報老是讓人頭疼，自動化處理起來特麻煩。DeepSeek 能幫你把這些非結構化數據，變成好用的結構化信息。

**第二步：利用 DeepSeek 提取財報關鍵數據**
假設我哋手上有個公司的 PDF 財報。我們得先把它裡的內容提取成純文字。市面上有很多 Python 庫能辦這事，比如 `PyPDF2` 或者 `pdfminer.six`。搞定文字提取後，就可以設計提示詞給 DeepSeek 去分析了。

一個好的提示詞，要清楚告訴模型你想抓哪些信息，例如：「請從以下財報文本中，抽取公司名稱、報告期、總收入、淨利潤、每股收益 (EPS) 以及負債比率。請以 JSON 格式回應。」

```python
financial_report_text = """
# 香港某科技公司 2023 年度財務報告概要
公司名稱：創新科技集團有限公司 (Innovation Tech Group Ltd.)
報告期：截至 2023 年 12 月 31 日
主要財務數據：
- 總收入：港幣 150 億元
- 銷售成本：港幣 70 億元
- 毛利：港幣 80 億元
- 營運開支：港幣 40 億元
- 營運利潤：港幣 40 億元
- 淨利潤：港幣 30 億元
- 每股收益 (EPS)：港幣 2.50 元
- 總資產：港幣 1000 億元
- 總負債：港幣 400 億元 (其中流動負債 200 億元)
- 負債比率：40%
市場評論：公司在 AI 產品開發上取得顯著進展，預計未來增長強勁。
"""

prompt_financial = f"""
你是一個資深的財經分析師。請從以下財報文本中，精準地抽取關鍵財務指標。
需要提取的指標包括：公司名稱、報告期、總收入、淨利潤、每股收益 (EPS)、負債比率。
請以嚴格的 JSON 格式回應，如果某項數據未能找到，請標記為 null。

財報文本：
{financial_report_text}
"""

response = client.chat.completions.create(
    model="deepseek-v2", # 或 deepseek-chat, 視乎你的訪問權限和需求
    messages=[
        {"role": "system", "content": "你是一個專業的財經數據抽取工具。"},
        {"role": "user", "content": prompt_financial}
    ],
    temperature=0.1, # 降低溫度以獲取更確定性的結果
    response_format={"type": "json_object"}
)

print(response.choices[0].message.content)
```

DeepSeek 的 JSON 模式可以保證輸出是有效 JSON 格式，方便你後續用程序處理。

## 情緒因子提煉：新聞與社交媒體分析
新聞和社交媒體的情緒往往影響短期股價波動。用 DeepSeek 搞實時情感分析，能幫你更好地捕捉市場情緒變化。

**第三步：自動化分析新聞情緒因子**
首先，你需要一個新聞源，比如財經新聞網站的 RSS Feed，或者通過 API 訂閱相關數據。拿到新聞標題和內文後，就可以傳給 DeepSeek 進行情感分析了。

一個不錯的提示詞範例：「請分析以下新聞標題與內文，判斷其對 '創新科技集團有限公司' 股價的潛在影響。請將情緒分為『正面』、『中性』、『負面』，並提供一個 1 到 5 分的情緒分數 (1 最負面，5 最正面) 以及簡要解釋。請以 JSON 格式回應。」

```python
news_title = "創新科技集團發佈劃時代 AI 晶片，股價大漲 15%"
news_content = "香港創新科技集團今日宣佈成功研發出新一代人工智能晶片，性能領先行業，預計將大幅提升公司市場競爭力。消息一出，投資者信心大增，股價盤中一度飆升 15%。分析師普遍看好其未來發展。"

prompt_sentiment = f"""
你是一個專業的金融市場情緒分析師。請分析以下新聞標題與內文，判斷其對『創新科技集團有限公司』股價的潛在影響。
請將情緒分為『正面』、『中性』、『負面』，並提供一個 1 到 5 分的情緒分數 (1 最負面，5 最正面)。
最後，提供一句簡要的解釋。請以嚴格的 JSON 格式回應。

新聞標題：{news_title}
新聞內文：{news_content}
"""

response_sentiment = client.chat.completions.create(
    model="deepseek-v2",
    messages=[
        {"role": "system", "content": "你是一個專業的金融市場情緒分析工具，擅長分析中文新聞。"},
        {"role": "user", "content": prompt_sentiment}
    ],
    temperature=0.3, # 可以稍微提高溫度增加多樣性，但對於情緒分析，低溫通常更好
    response_format={"type": "json_object"}
)

print(response_sentiment.choices[0].message.content)
```

通過定期運行這個分析，你就能建立一個實時的新聞情緒數據庫，把它作為你量化交易策略的一個因子。

## 優化與實踐建議
想讓 DeepSeek 在量化交易中發揮最大作用，有幾點優化建議。我上次拿 DeepSeek 跑港股上市公司年報時，就發現只要你的提示詞夠精準、要求夠明確，它對中文財經術語的理解能力，真的能讓你大吃一驚！

*   **提示詞工程 (Prompt Engineering)**：這絕對是核心中的核心！你的提示詞越清晰、越具體，模型的輸出就越準。試試加入「你是一個專業的 XX 分析師」這類角色設定，並指定輸出格式 (比如 JSON)。
*   **數據質量**：模型輸出好不好，直接看你輸入數據。確保你的財報文本和新聞數據是準確、完整且乾淨的。對於繁體中文的特殊用詞和香港常用的財經術語，可以考慮建立一個詞彙表，或者在提示詞中提供上下文。
*   **結合其他因子**：DeepSeek 提供的情緒因子和財報數據只是量化交易策略的一部分。把它跟技術指標、宏觀經濟數據等結合起來，能構建更全面的交易模型。
*   **持續監測與迭代**：市場和語氣都在變，你得定期看看 DeepSeek 的分析結果，不對勁就調調提示詞和參數，甚至可以考慮用自己的數據微調 (Fine-tuning) 模型。

## 常見問題

*   **DeepSeek V2 適合處理長篇財報文件嗎？**
    DeepSeek V2 的上下文窗口（能讀懂的文本長度）很大，處理數千甚至上萬字的長篇財報文件是可行的。但為了效率和準確性，建議先分塊處理長文，或者只提取關鍵章節給模型分析。
*   **如何處理 DeepSeek 分析結果的「幻覺」(Hallucination) 問題？**
    「幻覺」這玩意兒，是大模型都躲不開的問題。為了降低風險，你可以：
    1.  在提示詞中明確要求模型「只從原文中提取」或「如果找不到則回復 null」。
    2.  對模型輸出進行二次驗證，例如將抽取的數字和財報原文核對。
    3.  使用較低的 `temperature` 參數，減少模型生成的隨機性。
*   **對於數據私隱問題，香港中小企有什麼選擇？**
    如果你擔心數據私隱，可以考慮 DeepSeek 提供的私有化部署方案，把模型跑在自己的服務器或者信任的雲端環境。另外，確保你使用的 DeepSeek API 符合 GDPR 或者香港個人資料（私隱）條例的要求，並簽好數據處理協議。
