## DeepSeek 實戰教學：三招搞定吸睛車評文

就攞 DeepSeek v3.0 API 嚟講啦，我今年 5 月實測過，發現只要學識下面呢三招，包你輕鬆搞掂篇正斗車評文！

### 第一招：精準落 Prompt (Prompt Engineering)

呢步係重中之重！AI 寫出嚟靚唔靚，就睇你個 Prompt 俾得夠唔夠 detail、夠唔夠準。一個好嘅 Prompt 記得要包晒下面啲料：

*   **角色設定**：例如「你係位專業車評人，最鍾意用輕鬆幽默嘅香港口語寫車評。」
*   **任務要求**：講清楚要寫篇乜嘢車評，目標讀者係邊啲人（好似：首次買樓家庭、後生仔、公司商務租車）。
*   **車輛核心資訊**：品牌、型號、年份、主要配置（例如：真皮櫈、天窗、自動泊車、雙波箱）、咪數、賣點（例如：慳油、大空間、性能勁）。
*   **文章結構同風格**：建議包埋開場白、外形、內櫳同空間、揸車感受、功能配置、優缺點分析、總結等等。語氣方面，可以指定「香港口語化」、「專業又客觀」、「輕鬆活潑」咁。
*   **香港本地元素**：明確要求加啲香港人常用嘅詞語或場景（好似：泊車難、假日一家大細去郊外、返工放工塞車、牌費貴）。
*   **字數限制**：方便你控制文章長度。

**範例提示詞：**

「請你以一位熟悉香港汽車市場、用輕鬆地道口語化語氣嘅汽車評測員身份，為以下車輛撰寫一篇約 800 字嘅評測文章。目標讀者係尋求實用家庭用車嘅香港中產家庭。文章需包括外觀、內櫳、駕駛感受、實用性（如尾箱空間、泊車便利度）、優缺點，並加入香港生活元素同建議。

**車輛資料：**
*   **品牌/型號**：Honda Stepwgn Spada (2018 年版)
*   **特點**：七人車、雙電動趟門、低地台、魔術尾門 (Waku Waku Gate)、慳油、維修成本低、牌費平。
*   **里程**：約 50,000 公里
*   **賣點**：適合香港多成員家庭，日常接送小朋友或假日出遊都好方便，性價比高。

請以『**家庭摯愛新選擇：2018 Honda Stepwgn Spada 香港實測**』為題。」

### 第二招：DeepSeek 自動生成同初審

將你砌好嘅 Prompt 丟畀 DeepSeek 個對話框，或者直接用 API 傳送請求，DeepSeek 好快就出篇初稿畀你。我試過幾次，就算係同一個 Prompt，每次出嚟嘅嘢都可能少少唔同，所以如果第一次唔夠滿意，咪再 Regenerate 多幾次囉。

收到初稿後，你就要快速睇一次，檢查下面幾點：

*   **內容齊唔齊**：有冇包含你 Prompt 要求嘅所有部分？
*   **事實準唔準**：雖然 AI 識好多嘢，但關於車輛型號、配置等具體資訊，最好核對返一次，確保冇錯漏。
*   **語氣風格**：係咪符合你設定嘅輕鬆、地道風格？有冇出現太多生硬嘅書面語？
*   **邏輯通唔通**：文章嘅段落之間接駁得自然嗎？

### 第三招：人手執靚加香港味

AI 寫出嚟嘅嘢，講到底都係個「骨架」嚟㗎啫。想佢變到真係可以打動人嘅好文，人手執靚佢係必須嘅！呢步最緊要就係加「本地味」同「人情味」落去：

*   **執靚啲字眼**：將 AI 較為通用嘅詞語，換成更多香港人常用嘅口語或俗語。例如將「後備箱」改為「尾箱」，「變速箱」改為「波箱」，加入「牌費」、「驗車」、「咪數」、「劏車」等本地詞彙，聽落就貼地好多。
*   **加啲真情實感**：雖然係 AI 寫，但你可以巧妙地加入一啲你或者你嘅客戶嘅「真實」感受，例如「上週我試揸呢部車，發現佢喺香港啲窄路轉彎都好靈活，泊位真係冇難度㗎。」或者「有客戶反映，佢嘅低地台設計，對屋企有老人家或者小朋友嘅家庭特別方便，真係好體貼！」
*   **催化劑！加強銷售力**：加入更多銷售導向嘅內容，例如強調租賃或購買呢款車會帶嚟嘅好處，仲要加 Call to action (CTA)，好似「即刻預約試駕」或「了解更多租賃詳情」咁，引導客戶行動。
*   **執番個靚仔排版**：適當加入小標題、列表、粗體字，令文章更易讀。呢個步驟都係一個好機會去將圖片嵌入文章，令版面更豐富，睇落更專業。

## 常見問題

**Q1: DeepSeek 生成嘅內容會唔會太「行貨」？點樣先可以寫得更有特色，唔會太『行』？**

**A1:** 初稿有時可能會比較通用，但你可以透過第二招同第三招去優化。關鍵係喺 Prompt 中加入更具體、更獨特嘅車輛賣點，甚至可以提供一些真實嘅用家故事或者情景。優化時，大膽啲，加啲香港獨有嘅使用場景，例如「行大欖隧道上斜」嘅真實表現，或者「喺旺角搵位泊車」係咪真係方便到喊。

**Q2: 點樣確保車評事實準確？AI 會唔會亂咁「作故仔」？**

**A2:** AI 有時可能會「幻覺」出錯嘅資訊，特別係關於年份、特定配置等。所以，初稿生成後，**人手核對係非常重要嘅一步**。務必對照官方資料、車輛規格表或者二手車平台嘅詳細描述，確保所有數據都係準確無誤嘅，唔好畀 AI 陰到你！

**Q3: DeepSeek 識唔識用香港本地詞語？使唔使自己逐個改？**

**A3:** DeepSeek 繁體中文係 OK 嘅，但要佢完全變身「香港通」仲有啲難度。喺 Prompt 中明確要求「使用香港地道口語詞彙」，並提供一些常見例子，會有助於 AI 生成更本地化嘅內容。生成後，喺人手優化階段再進行細緻嘅潤飾同替換，係最穩妥嘅做法。

**Q4: 除咗車評，仲可以應用 DeepSeek 喺香港汽車行業嘅邊度？**

*   租車服務嘅推廣文案，勁吸客！
*   二手車盤嘅吸引人描述，快手出貨！
*   常見問題解答 (FAQ) 內容，慳番口水。
*   客戶查詢嘅自動回覆模板，效率高！
*   汽車保養小貼士嘅博客文章，養客一流！
*   公司社交媒體嘅日常帖文，日日有嘢出！
